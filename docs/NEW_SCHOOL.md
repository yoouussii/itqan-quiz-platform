# إعداد مدرسة جديدة على منصة إتقان

كل مدرسة لها **قاعدة بيانات منفصلة** و**موقع منفصل** من نفس الكود. بيانات كل مدرسة معزولة تماماً عن غيرها، وأي تحديث للكود يصل لكل المدارس تلقائياً.

الوقت المتوقع: حوالي 20 دقيقة.

---

## ١. قاعدة البيانات (Supabase)
1. من [supabase.com](https://supabase.com/dashboard) اضغط **New project**:
   - **Name:** اسم المدرسة بالإنجليزي، مثل `school2-itqan`.
   - **Database Password:** اضغط Generate واحفظها في مكان آمن.
   - **Region:** أقرب منطقة متاحة للسعودية.
2. انتظر حتى يجهز المشروع، ثم اضغط زر **Connect** أعلى الصفحة ← **Session pooler** ← انسخ الرابط.
   ضع كلمة مرور قاعدة البيانات مكان `[YOUR-PASSWORD]`.
   > استخدم رابط **Session pooler** وليس Direct connection، لأن خوادم GitHub لا تدعم IPv6.

## ٢. حفظ الرابط في GitHub
GitHub ← المستودع ← **Settings ← Secrets and variables ← Actions ← New repository secret**:
- **Name:** `DB_URL_SCHOOL2` (اسم واضح لكل مدرسة)
- **Secret:** الرابط من الخطوة السابقة

## ٣. تجهيز قاعدة البيانات بزر واحد
GitHub ← **Actions ← Setup new school ← Run workflow**:

| الخانة | القيمة |
|---|---|
| db_secret | `DB_URL_SCHOOL2` (اسم السر نفسه) |
| school_name | اسم المدرسة كما يظهر للطلاب |
| admin_national_id | رقم هوية مدير النظام في المدرسة |
| admin_name | اسمه |

السكربت ينشئ الجداول، ويشغّل كل ملفات الحماية بالترتيب، وينشئ حساب المدير بكلمة المرور **itqan123** (يُطلب منه تغييرها عند أول دخول).
في آخر السجل يجب أن يظهر: `كلمات مرور بنص صريح (يجب 0): 0`.

> السكربت يرفض العمل على قاعدة بيانات فيها مستخدمون، حتى لا تُشغَّله بالخطأ على مدرسة قائمة.

## ٤. الموقع (Vercel)
1. Supabase ← المشروع الجديد ← **Project Settings ← API** (أو Data API): انسخ **Project URL** ومفتاح **anon public**.
   > لا تستخدم مفتاح `service_role` أبداً في الموقع.
2. [vercel.com](https://vercel.com/new) ← **Add New ← Project** ← اختر نفس المستودع `itqan-quiz-platform`.
3. **Project Name:** مثل `itqan-school2`.
4. **Environment Variables:**
   - `VITE_SUPABASE_URL` = Project URL
   - `VITE_SUPABASE_ANON_KEY` = مفتاح anon
5. **Deploy**.

## ٥. الدومين (اختياري)
1. Vercel ← المشروع ← **Settings ← Domains** ← اكتب مثلاً `school2.itqan.com`.
2. في Cloudflare ← الدومين ← **DNS** ← أضف سجلاً:
   - Type: `CNAME`، Name: `school2`، Target: `cname.vercel-dns.com`
   - **Proxy status: DNS only** (السحابة رمادية)
3. خلال دقائق يعمل الدومين بشهادة HTTPS مجانية.

## ٦. أول دخول
1. ادخل برقم هوية المدير وكلمة المرور `itqan123`، ثم غيّرها.
2. **الإعدادات ← هوية المدرسة:** الاسم والشعار ولون الواجهة.
3. **المواد والشعب ← الفروع:** إن كان للمدرسة فروع.
4. **المستخدمون:** استيراد الطلاب والمعلمين من Excel، ومعه حسابات أولياء الأمور.

## تحديثات لاحقة
- **الكود:** أي دمج في `main` ينشره Vercel لكل المدارس تلقائياً.
- **ملف SQL جديد** (مثل `013_...sql`): شغّله لكل مدرسة من **Actions ← Supabase migrate**، واكتب في خانة `db_secret` اسم سر المدرسة. اتركها `SUPABASE_DB_URL` للمدرسة الأساسية.

## لوحة صاحب المنصة والاشتراكات
لوحة واحدة تعرض كل المدارس المشتركة: عدد الطلاب والمعلمين وأولياء الأمور، والنشاط، والمساحة، وتاريخ انتهاء الاشتراك.
1. أضف سراً باسم `OWNER_KEY` في **Settings ← Secrets and variables ← Actions** (مفتاح طويل عشوائي، 16 حرفاً على الأقل). المفتاح نفسه لكل المدارس، فاحفظه في مكان آمن.
2. لكل مدرسة موجودة: شغّل **Supabase migrate** على `038_owner_license.sql`، ثم **Actions ← Set owner key** واكتب اسم سر قاعدة بياناتها. (المدارس الجديدة يُضبط مفتاحها تلقائياً في **Setup new school** إن كان السر موجوداً.)
3. افتح `https://رابط-المنصة/owner` وأدخل المفتاح. المدرسة الحالية تظهر تلقائياً، وأضف باقي المدارس برابط Supabase والمفتاح العام (anon) لكل منها.
4. من زر **الاشتراك** حدد الخطة وتاريخ الانتهاء وحد الطلاب. قبل الانتهاء بـ14 يوماً يظهر تنبيه لمدير المدرسة، وعند الانتهاء يمكن (اختيارياً) إيقاف المنصة لغير مدير النظام حتى التجديد. المدرسة بلا اشتراك محدد تعمل بلا قيود.

## النسخ الاحتياطي
- خطة Supabase **Pro** تحفظ نسخة يومية تلقائياً (آخر 7 أيام)، ولا يتوقف المشروع لعدم النشاط.
- سير العمل `Supabase backup` و`Supabase keep-alive` مضبوطان للمدرسة الأساسية فقط.

## التكلفة التقريبية
- Supabase Pro: 25 دولار شهرياً تشمل أول مشروع، وكل مدرسة إضافية حوالي 10 دولار شهرياً.
- Vercel Pro: 20 دولار شهرياً لكل الحسابات والمشاريع.
- الدومين: حوالي 10 دولار سنوياً، والدومينات الفرعية مجانية.
