# النسخ الاحتياطي اليومي على Google Drive

كل ليلة (3:23 فجراً بتوقيت السعودية) تُؤخذ نسخة كاملة من قاعدة البيانات وتُرفع إلى مجلد
**«إتقان - نسخ احتياطية»** في Google Drive (حساب المدرسة نفسه المستخدم لمرفقات الواجبات).

- تُحفظ **آخر 30 نسخة**، والأقدم يُحذف تلقائياً (يمكن تغيير العدد عند التشغيل اليدوي).
- المجلد **خاص**: أنشأته المنصة بإذن `drive.file`، ولا يُشارك مع أحد.
- النسخة تشمل كل بيانات المنصة: المستخدمين، كلمات المرور (مشفّرة)، الاختبارات والنتائج، الحضور، السلوك، الواجبات، السجلات…
- حالة آخر نسخة تظهر للمدير في **إدارة العام الدراسي ← النسخة الاحتياطية**.

## التفعيل (مرة واحدة)

الأسرار المطلوبة موجودة غالباً من إعدادات سابقة:

| السر | من أين |
|---|---|
| `SUPABASE_DB_URL` | من إعداد «Supabase migrate» |
| `GOOGLE_CLIENT_ID` و `GOOGLE_CLIENT_SECRET` و `GOOGLE_REFRESH_TOKEN` | من إعداد «Setup Drive storage» ([DRIVE_STORAGE.md](DRIVE_STORAGE.md)) |
| `BACKUP_PASSPHRASE` *(اختياري)* | كلمة سر طويلة تختارها، لتشفير النسخة قبل رفعها. **احفظها في مكان آمن**؛ بدونها لا يمكن فتح النسخ المشفّرة. |

ثم من GitHub: **Actions ← Daily backup to Drive ← Run workflow**. بعد أول تشغيل ناجح يعمل تلقائياً كل ليلة.

> GitHub يوقف المهام المجدولة إن لم يحدث أي تغيير على المستودع 60 يوماً. إن ظهر في المنصة
> «لم تُنشأ نسخة تلقائية منذ أكثر من يومين» افتح Actions وفعّل المهمة من جديد (Enable workflow).

## الاسترجاع

الملف بصيغة `pg_dump` المضغوطة (`.dump`، أو `.dump.gpg` إن كان مشفّراً).

1. نزّل النسخة المطلوبة من مجلد Drive.
2. إن كانت مشفّرة:
   ```bash
   gpg -d itqan-backup-YYYY-MM-DD_HHMM.dump.gpg > backup.dump
   ```
3. الاسترجاع في مشروع Supabase **جديد وفارغ** (الأسلم، ثم تغيّر رابط المنصة إليه)، أو في المشروع نفسه بعد التأكد:
   ```bash
   pg_restore --no-owner --clean --if-exists -d "postgresql://...رابط Session pooler..." backup.dump
   ```
   رسالة `schema "public" already exists` طبيعية ولا تؤثر.
4. في SQL Editor نفّذ: `notify pgrst, 'reload schema';`

> يلزم `pg_restore` بإصدار 15 أو أحدث (يأتي مع PostgreSQL، أو عبر `brew install libpq` على Mac).
> إن احتجت مساعدة في الاسترجاع اطلبها قبل تنفيذ `--clean` على المشروع الأساسي، لأنه يستبدل البيانات الحالية.
